## 🎯 ¿Qué significa la Licencia MIT?

La Licencia MIT permite que cualquier persona pueda:

### ✅ Permisos
- **Usar** el software para cualquier propósito
- **Modificar** el código fuente
- **Distribuir** copias del software
- **Vender** el software
- **Sublicenciar** bajo otras licencias
- **Usar en proyectos comerciales**

### ❌ Limitaciones
- **No hay garantías** - El software se proporciona "tal como está"
- **No hay responsabilidad** - Los autores no son responsables de daños
- **Debe incluir** el aviso de copyright y la licencia en todas las copias
